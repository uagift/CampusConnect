# 🎓 CampusConnect 1.0

> **Discover. Connect. Belong.**

CampusConnect is a student-centered React web application designed to make it easier for students to discover campus events, workshops, clubs, competitions, leadership opportunities, and community activities — all in one place.

## ✨ Features

- 🔎 Search and filter campus opportunities
- 📅 Browse events and activities
- 📋 Dynamic event detail pages
- ❤️ Save activities for later
- 🤝 Join activities
- 📱 Responsive design for mobile, tablet, and desktop
- 🧭 SPA navigation with React Router
- 🎨 Custom visual identity inspired by calm, energetic, and community-focused design

## 🛠️ Built With

- React
- Vite
- React Router DOM
- Context API
- CSS

## 🧠 What I Learned

Through CampusConnect, I practiced:

- Building reusable React components
- Passing data through props
- Managing UI state with `useState`
- Sharing application state with Context API
- Dynamic routing with React Router
- Filtering and searching data
- Designing responsive interfaces
- Structuring a scalable React application
